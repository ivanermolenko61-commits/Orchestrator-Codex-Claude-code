## Живые сценарии и ограничения

Оба направления автор/reviewer на Python, независимые единицы, смена lead и интеграция завершены с VERIFIED. Прямой Codex-автор получил Qwen FIX (два ID), исправил код и получил PASS: ноль фоновых вызовов автора. Финальный повтор: автор Codex исправил F1/F2 и выполнил checks; координатор Qwen отправил тот же SHA на независимое Qwen review и завершил задачу VERIFIED. Два вызова Qwen (вход 3866, выход 2780, кэш 1024), ноль вызовов автора. Другой SHA без авторской фиксации блокируется до оплаты; обе стороны этой защиты проверены регрессией. Полный прогон и контрольные утверждения выполнены отдельно от авторских тестов.

Измерения, расход каждого сервиса и оговорки — в [benchmark](../../benchmarks/2026-11-20-codex-qwen.md). Один последовательный/параллельный замер не доказывает стабильный процент экономии. Реальный сетевой обрыв намеренно не создавался; восстановление, неверный JSON, бюджеты, блокировки и остановка без прогресса проверяются офлайн.

Прямая реализация принадлежит закреплённому автору; при смене координатора он делегирует этому автору. Для передачи координации автор коммитит правки и выполняет checks; любой чат может отправить тот же SHA на независимое review. Новый SHA требует новой авторской фиксации. Принятые кандидаты можно интегрировать и завершать из другого чата. Защищённые файлы правит тимлид, оба фоновых автора имеют одинаковые ограничения JSON-правок. Старые задачи не переименовываются, изменённые назначения требуют свежей приёмки при сохранении расхода.

Загрузка общего навыка именно интерфейсами двух новых чатов VS Code проверяется после разрешённой рабочей установки; CLI-проверки не заменяют этот шаг. Порядок выпуска и возврата — [release](../../release-codex-qwen.md). Claude остаётся на паузе, личные настройки, входы и MCP не изменяются.
