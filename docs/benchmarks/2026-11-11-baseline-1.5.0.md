## Дефекты, найденные замером (чинить в ветке fix перед этапом B)
- **A-1.** Чисто серверная `start` создаёт пустую единицу `main` без файлов: автор Claude для неё не запускается, `finish` пишет «не подтверждена» при принятой рабочей единице. Нужно: не создавать пустую `main` или брать файлы из `--task-file`; `finish` не считает открытой единицу без файлов и правок; регрессионный тест на оба.
- **A-2 (MAJOR, 2 из 3 frontend-задач).** Автор Codex без инструментов пишет в `unmet_requirements` «невозможно запустить тесты»; движок превращает PASS reviewer в FIX, автору уходит FIX без замечаний, он делает пустую правку или правку «ради правки» → зелёный кандидат не принимается, расход впустую (S3: 2 вызова, R2: 4 вызова).
- **A-3.** Повтор после `--continues` получает причину `continues` вместо `cli_failure`; в отчёте продолженной задачи оборванный вызов не показан строкой с «токены неизвестны» (виден только число «перенесено 1»).
- **A-4.** Ревью, идущее после PASS, превращённого в FIX, получает причину `неизвестно` (R2: review:2, review:3).
- **A-5 (проверить).** Нулевой cached_input Codex (см. выше).
