# Выпуск новой пары

Рабочая установка и публикация требуют подтверждения владельца по AGENTS.md. До подтверждения допускаются локальный кандидат, независимая приёмка, архив и установка в отдельный home. `~/.claude/PAUSED` сохраняется.

После независимой приёмки и разрешения:

1. Проверить чистоту ветки `feat/codex-qwen`, SHA приёмки и отсутствие изменений исполняемых файлов после него. Пересчитать/проверить manifest. Опубликовать принятую ветку; слияние выполнять с сохранением изменений существующего main и исторических записей, не через reset/force.
2. Выполнить `python scripts/install-pair.py` (сверка), затем `--apply`; сохранить путь резерва. Проверить нулевую повторную сверку и `--help` установленного движка. Не запускать исторический установщик с CLAUDE_HOME для включения новой пары.
3. Актуализировать **только инструкции** ai-knowledge в глобальных AGENTS.md Codex (или непустом AGENTS.override.md) и QWEN.md Qwen: применить свежие управляемые блоки из базы, сохранив остальные правила. Не переустанавливать заодно runtime хуков из старого main базы: у него есть отдельный кандидат исправлений. Не менять config.toml/settings.json, входы и MCP. Общий C:/Projects/AGENTS.md должен разрешать установленную пару и сохранять паузу Claude. Старые проектные назначения frontend/backend заменить правилом общего навыка там, где они действительно действуют; проектный route/coordinator сохраняется.
4. Открыть новые чаты Codex и Qwen в VS Code. В каждом проверить, что найден один активный навык agentq с текущим VERSION и одинаковой инструкцией, выполнить `route` и `status --json` одного тестового проекта с соответствующим `--lead`. Восстановить назначения и следующий шаг из существующей `.ai/`, не начинать второй start. CLI-проверка `--lead` сама по себе не доказывает загрузку навыка интерфейсом VS Code.
5. Проверить один небольшой прямой цикл из установленного пути, независимый PASS, полный прогон и finish. Сверить личные настройки с предустановочными контрольными суммами. Зафиксировать фактический выпуск/установку и ограничения в базе знаний, не объявлять их до выполнения.

Возврат: резерв содержит прежние файлы и receipt со списком затронутых путей. Восстановить существовавшие файлы из резерва; добавленные новые точки входа отключить переименованием каталогов agentq в `.agents/skills` и `.qwen/skills`, сохранив содержимое. Вернуть только изменённые управляемые инструкции из их отдельного резерва. `.ai/` и старые worktree не удалять и не переименовывать историю. Возврат к запуску Claude требует прямого указания владельца; отключение новой пары само по себе Claude не включает.
