# Agentq v1 — общие правила

Для задач с /agentq читать ~/.claude/skills/agentq/SKILL.md и следовать выбранному маршруту.
Если в проекте есть собственный координатор, использовать его без второго глобального цикла.
Claude ведёт задачу и пишет бэкенд; Codex пишет фронтенд; другой сервис независимо ревьюит изменения.
Проверки и приёмку привязывать к точному коммиту, сохранять историю и бюджет.
Читать AGENTS.md проекта до работы; менять только согласованные файлы.
Не читать и не выводить секреты. Публикацию, слияние и деплой выполнять в пределах разрешения владельца.
Не запускать дополнительные агенты и повторные модельные проверки без необходимости.
Бюджет вести отдельно для каждой конкретной задачи плана и фиксировать вместе с критериями готовности до выполнения.
После принятия задачи следующая начинает расход с нуля; история закрытых задач сохраняется для аудита и бюджет следующей не уменьшает.
Внутри незавершённой задачи суммировать вызовы автора, исправления и ревью; новый чат, переименование и повторный запуск расход не обнуляют (`--continues`).
Общий бюджет нескольких задач применять только по явному указанию владельца такого охвата; своего общего предела не вводить.
